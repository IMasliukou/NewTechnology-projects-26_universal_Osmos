# Перенос существующих проектов в KiCad

Сюда кладём **исходные файлы от заказчика** (P-CAD, Altium, PDF) для переноса в
KiCad. Готовый результат (`.kicad_pro/.kicad_sch/.kicad_pcb`) сохраняем в
`projects/<имя>/` и коммитим в git.

## Что установленный KiCad 9 умеет импортировать (проверено)

| Источник | Схема (eeschema) | Плата (pcbnew) |
| --- | --- | --- |
| **Altium** `.SchDoc` / `.PcbDoc` | да | да (бинарный PcbDoc v6) |
| Altium Circuit Maker / Circuit Studio | да | да |
| **P-CAD 200x ASCII** `.pcb` | — (нет) | **да** |
| CADSTAR | да | да |
| EAGLE | да | да |
| EasyEDA (Std / Pro) | да | да |
| Fabmaster | — | да |
| LTspice | да | — |

Вывод: **схемы P-CAD напрямую KiCad не читает**, платы P-CAD (ASCII `.pcb`) — читает.

## Пути переноса по типу источника

### 1. Есть Altium `.SchDoc` (лучший вариант) → импорт в KiCad
Это даёт **редактируемую схему** с компонентами и связями (не картинку).

- В Altium сохраните файл в актуальном бинарном формате (`*.SchDoc`, `*.PcbDoc`).
- В KiCad: `File → Import → Non-KiCad Project…` (импорт всего проекта: схема + плата),
  либо в eeschema `File → Import → Import Non-KiCad Schematic…` и выбрать Altium.
- Проверьте ERC, при необходимости поправьте символы (`Tools → Update Symbols from Library`).

### 2. Есть плата P-CAD в ASCII (`*.pcb`) → импорт в pcbnew
- В pcbnew: `File → Import → Non-KiCad Board File…`, выбрать формат P-Cad.
- Требуется именно **ASCII**-выгрузка P-CAD (не бинарь).

### 3. Есть только P-CAD-схема (без Altium) → два варианта
- **Через Altium:** открыть P-CAD в Altium, сохранить как `.SchDoc`, дальше пункт 1.
- **Перерисовать по PDF** (пункт 4), если Altium недоступен.

### 4. Есть только PDF → перерисовать вручную (образец)
PDF — это картинка, **связей (нетлиста) в нём нет**, автоматически схему из него не получить.

- Сделайте растровый образец нужной страницы:
  ```bash
  pdftoppm -png -r 300 imports/<файл>.pdf imports/ref
  ```
- Создайте проект из шаблона (`templates/project-template`) и в eeschema
  через `Place → Add Image` положите образец как подложку, чтобы перерисовать поверх.
- Нарисуйте схему заново, затем удалите подложку.

## После импорта/отрисовки (для любого пути)

1. Сохраните проект в `projects/<имя>/` под именем проекта.
2. Прогоните проверку и экспорт:
   ```bash
   scripts/export.sh projects/<имя>
   ```
3. Убедитесь, что ERC без ошибок (`output/<имя>/<имя>.erc`).
4. Закоммитьте `.kicad_*` файлы в git. Артефакты (`output/`) не коммитим.
