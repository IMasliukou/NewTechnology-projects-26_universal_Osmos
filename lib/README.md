# Общие библиотеки ModernTechnologies

Здесь хранятся **общие для всех проектов** символы, чтобы у заказчика был единый
набор обозначений. Проекты — **схемы электрики (автоматизация), без печатных плат**,
поэтому нас интересуют в первую очередь **символы для схем** (`*.kicad_sym`).
Посадочные места/футпринты обычно **не нужны**.

Структура:

- `symbols/` — общие символы (`*.kicad_sym`) для схем (eeschema).
- `footprints/` — (опционально) если для отдельных задач всё же нужны футпринты.

## Готовые библиотеки KiCad, полезные для электрики/автоматики

Их можно использовать сразу (стандартные библиотеки KiCad):

- `Relay`, `Relay_SolidState`, `Driver_Relay` — реле, твердотельные реле (в т.ч. как контакторы).
- `Switch` — кнопки, выключатели, концевики, переключатели, селекторы.
- `Motor`, `Driver_Motor` — двигатели и приводы.
- `Valve` — клапаны.
- `Transformer` — трансформаторы.
- `Sensor`, `Sensor_Temperature`, `Sensor_Pressure`, `Sensor_Proximity`, `Sensor_Current`, … — датчики.
- `Power_Protection` — предохранители/защита; `Device` — предохранитель, термистор, лампа и т.д.
- `Connector`, `Connector_Generic` — клеммы/разъёмы (клеммники моделируем разъёмами `Conn_01xNN`).
- `power` — символы питания/«земли» и глобальные цепи (L/N/PE, +24V и т.п.).

## Свои символы ModernTechnologies

Чего в стандартных библиотеках нет для электрики (контакторы по ГОСТ/МЭК,
пускатели, автоматы QF, PLC-модули с раскладкой I/O, клеммники с нумерацией) —
рисуем сами и складываем в `symbols/ModernTech.kicad_sym`. Подключение в проекте
через `sym-lib-table` (переменная `${KIPRJMOD}`):

```
(lib (name "ModernTech")(type "KiCad")(uri "${KIPRJMOD}/../../lib/symbols/ModernTech.kicad_sym")(options "")(descr "ModernTechnologies shared symbols"))
```

Пока своих символов нет — используем стандартные библиотеки KiCad из списка выше.
